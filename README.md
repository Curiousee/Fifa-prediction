# ⚽ FootyPredict

A full-stack football prediction community for club matches, international fixtures, and major competitions throughout the season.

## Tech Stack

| Layer | Technology |
|-------|----------|
| Frontend | React 18 + TypeScript + Vite |
| Styling | Tailwind CSS |
| Charts | Recharts |
| Backend | Node.js + Express + TypeScript |
| Database | MongoDB + Mongoose |
| Auth | JWT |
| Icons | Lucide React |

---

## Features

- Predict match winners for featured league and international fixtures
- Community leaderboard with live rankings
- Discussion thread for fans to talk matchday predictions
- Admin tools to create matches and declare results
- Year-round rather than single-tournament focus
